LeetCode 9. 回文数

Thinking

题目：给一个整数 x，判断它是不是回文数。
回文数定义：正读和反读一样，例如 121 是回文；‑121 不是（负号在前面）；10 反转是 01 → 1，不是回文。

一、先整理直观观察（初步结论）

  1. 负数一定不是回文数：带负号，反转后符号位置改变，直接 return false
  2. 末尾是 0 的正数（除了0本身）一定不是回文：数字最高位不可能是 0
    • 例子：10，反过来是 01=1，不等
  3. x = 0 是回文数

    边界快速过滤：
    如果 x < 0 或者 (x % 10 == 0 && x != 0) → 直接 false

思路1：转字符串反转（最简单）

  1. 数字转字符串
  2. 字符串反转，对比原串
    优点：代码短、好写
    缺点：额外开辟字符串空间，不满足「不使用额外空间」的进阶要求

思路2：只反转后半部分数字（最优解法，原地逻辑）

核心思想：不用反转整个数字，只翻转右半边，和左半边对比
如果是回文：

  • 偶数位：前半段 = 反转后的后半段
    1221 → 前半 12，反转后半 12 → 相等 ✅
  • 奇数位：去掉中间一位之后相等
    12321 → 前半 12，反转后半去掉中间 3 → 12 ✅

怎么不断截取后半段？
设变量 reverted 保存反转后的后半段
循环条件：原始数字 > 反转后的后半段（代表还没走到一半）
每一轮：

  1. digit = x % 10 拿到最后一位
  2. reverted = reverted * 10 + digit 拼到反转数末尾
  3. x = x // 10 原数字砍掉最后一位

循环停止时有两种情况：

  1. 偶数长度：x == reverted
  2. 奇数长度：中间那一位在 reverted 的最后，所以判断 x == reverted // 10

完整逻辑流程整理

  1. 特殊情况判断
    • if x < 0 → false
    • if x %10 ==0 and x !=0 → false
  2. 初始化 reverted = 0
  3. while x > reverted：
    • reverted = reverted *10 + x %10
    • x = x //10
  4. 返回结果：x == reverted or x == reverted //10
