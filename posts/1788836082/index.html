LeetCode 9. 回文数

Thinking

给定数组 nums 和值 val，原地删除所有等于 val 的元素，返回新数组长度；不需要关心超出新长度之后的数组内容，空间复杂度要求尽量 $O(1)$。

核心思路：双指针（快慢指针）

  1. 慢指针 slow：代表新有效数组最后一个位置的下一位，用来存放不等于 val 的元素。
  2. 快指针 fast：遍历整个数组，逐个检查元素。
  3. 遍历规则：
    • 如果 nums[fast] != val：说明这个元素要保留，把它赋值给 nums[slow]，然后 slow += 1
    • 如果 nums[fast] == val：直接跳过，slow 不动
  4. 遍历结束，slow 的数值就是最终有效数组的长度。

简单例子
nums = [3,2,2,3], val = 3

  • fast=0：值=3 → 跳过
  • fast=1：值=2 → nums[0]=2，slow=1
  • fast=2：值=2 → nums[1]=2，slow=2
  • fast=3：值=3 → 跳过
    最终返回 slow = 2，数组前两位为有效结果 [2,2]

复杂度

  • 时间：$O(n)$，数组只遍历一次
  • 空间：$O(1)$，原地修改，不新建数组
